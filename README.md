# Айсберг «ку-ку курилки»

Интерактивная страница: 120 стикеров пака [kykykyrilka_by_TgEmodziBot](https://t.me/addstickers/kykykyrilka_by_TgEmodziBot)
разложены по слоям айсберга по двум критериям — токсичность и оригинальность.

- `index.html` — готовая страница, данные встроены внутрь, работает офлайн.
- `stickers/` — изображения стикеров (WebP).
- `stickers.json` — данные: отправители, текст, оценки.
- `PROMPT.md` — техническое задание, по которому всё собрано.
- `index.template.html` — шаблон, в него подставляются данные.

Оценки автоматические, по тексту стикеров: OCR (Windows.Media.Ocr, ru) вытаскивает надписи,
имена и статусы вырезаются, затем считаются токсичность и оригинальность.
Стикеры без распознанной подписи вынесены в отдельный блок.
